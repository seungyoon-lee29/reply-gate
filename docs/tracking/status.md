# 현재 위치

## 한 줄 요약

결정론 게이트(L1)가 실제로 동작하는 데까지 완성했다. 문의를 받아 근거를 모으고, 초안을 만들고,
기각하고, 한 번 다시 쓰고, 그래도 안 되면 인계하는 흐름 전체가 돌고 지표가 산출된다.

## 남은 것 (우선순위 순)

1. **의미 수준 검증(L2)** — L1 통과분만 claim 단위로 근거와 대조. 기각 재현율 0%가 이것이
   필요한 실측 근거다: 미끼 조항 5건 모두에서 모델이 값을 지어내지 않아 구조적 결함이
   만들어지지 않았고, L1 은 구조만 보므로 잡을 것이 없었다. 판정 계열은 생성과 달라야 한다
   (같은 계열이면 self-judging bias 로 검출률이 오염된다) — 계열 미정.
2. **검색 임계값·미끼 조항 재조정** — 무근거 문의 4건이 `answered` 로 끝났다. 유사도 0.3 이상으로
   관련 조항이 검색되고 모델이 "안내가 어렵다"를 근거 위에서 답하기 때문이다. 임계값 조정과
   미끼 강화가 다음 실측의 입력이다.
3. **RAG 심화** — 벡터 단독 → 하이브리드(BM25+벡터) → 리랭킹 비교, 단계별 recall@k·precision.
   청킹 전략 비교(고정 크기 vs 조항 단위). 기각 사유를 "생성 문제 vs 검색 실패"로 분해.
4. **지표 확장** — 게이트 도입 전후 hallucination 율, L1 필터링에 의한 상위 검증 호출 감소율
   → 건당 비용 절감.
5. **미결** — 대시보드(스택 미정), 웹훅 송출, 배포, MCP.

## 알려진 제약

- **인증 없음.** 실사용자·실운영이 없어 의도적으로 범위 밖에 두었다. 실운영에 올리려면
  인증·인가·레이트 리밋·전송 구간 암호화가 전부 새 결정 사항이다.
- **스키마 마이그레이션 도구 없음.** DDL 이 전부 `CREATE TABLE IF NOT EXISTS` 라 스키마를
  바꾸면 볼륨째 재생성해야 한다.
- **정상 실행 0건 SQL 은 처리 기록에 흔적이 없다.** 채택된 근거도 실패도 아니라서 저장할
  자리가 없다. 감사에 필요하면 스키마 변경 사안이다.
- `starlette` + `httpx` 조합에서 테스트 클라이언트 deprecation 경고 1건. 현재는 통과하지만
  상위 버전에서 깨질 수 있다.
