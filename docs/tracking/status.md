# 현재 위치

## 한 줄 요약

결정론 게이트(L1)가 실제로 동작하는 데까지 완성했다. 문의를 받아 근거를 모으고, 초안을 만들고,
기각하고, 한 번 다시 쓰고, 그래도 안 되면 인계하는 흐름 전체가 돌고 지표가 산출된다.

## 실측값 (2026-08-05, 라이브 3회 반복)

근거 산출물은 `reports/evaluation-live-{1,2,3}.{md,json}` 로 저장소에 커밋돼 있다.
**이 세 리포트는 목표치 확정 이전에 나온 실행이라 목표치 칸이 "미확정"으로 찍혀 있다** —
그 실행의 기록 그대로 두고 고치지 않는다. 목표치 대비 표는 다음 라이브 실행부터 실린다.

**측정 1 — L1 게이트 단위 정확도 (결정론, 픽스처 27건, 외부 호출 0회)**

- 구조적 오류 검출률 **100.0%** (19/19)
- 정상 초안 오탐률 **0.0%** (0/8)
- 사유 4종 각각 100% 검출, 오발화 0

**측정 2 — 파이프라인 판정 일치율 (골든셋 30건 × 3회, 실제 모델)**

| | 1회 | 2회 | 3회 | 합산 |
|---|---|---|---|---|
| 일치율 | 22/30 | 21/30 | 21/30 | **64/90 = 71.1%** |
| 미끼 기각 재현 | 1/5 | 0/5 | 0/5 | **1/15 = 6.7%** |
| p50 / p95 (ms) | 4,436 / 9,279 | 3,837 / 7,180 | 3,903 / 7,771 | — |
| 건당 토큰 | 1,316.1 | 1,245.3 | 1,287.7 | — |

3회 반복으로 확인된 것:

- **미끼 기각 재현율이 낮은 것은 잡음이 아니다.** 15회 중 14회 모델이 값을 지어내지 않았다.
- **L1 은 end-to-end 로 실제 발화한다** — 90 케이스-실행 중 12회 기각, 전부
  `missing_citation`. 무근거 문의 G21–G24 는 12회 중 11회 기각 → 재생성 → 통과했다.
  기각 장면은 미끼가 아니라 **이 경로에서** 안정적으로 재현된다.
- **무근거 4건이 `answered` 로 끝나는 것도 3회 모두 같다** — 임계값 사안이 재현되는
  성질임을 확인했다.

정의는 `evaluation.TARGETS` 이고 리포트가 매 실행 대조한다 —
근거와 트레이드오프는 [결정 0006](decisions/0006-지표-목표치를-실측-뒤에-확정한다.md).

| 지표 | 목표 | 현재 | 판정 |
|---|---|---|---|
| 측정 1 구조적 오류 검출률 | ≥ 100% | 100.0% | 달성 |
| 측정 1 정상 초안 오탐률 | ≤ 0% | 0.0% | 달성 |

## 남은 것 (우선순위 순)

**다음 사이클은 1번(L2)이다** — 2026-08-05 확정. 미끼 기각 재현율 6.7% 를 생성 쪽 약화로
끌어올리지 않기로 한 결정의 이면이다([findings 1번](findings.md)).


1. **의미 수준 검증(L2)** — L1 통과분만 claim 단위로 근거와 대조. 미끼 기각 재현율
   6.7%(1/15)가 이것이 필요한 실측 근거다: 미끼 조항에서 모델이 값을 거의 지어내지 않아
   구조적 결함이 만들어지지 않았고, L1 은 구조만 보므로 잡을 것이 없었다. 남은 위험은
   "근거를 달았지만 그 근거가 답을 뒷받침하지 않는" 의미 층이다. 판정 계열은 생성과 달라야 한다
   (같은 계열이면 self-judging bias 로 검출률이 오염된다) — 계열 미정.
2. **검색 임계값·미끼 조항 재조정** — 무근거 문의 4건이 `answered` 로 끝났다. 유사도 0.3 이상으로
   관련 조항이 검색되고 모델이 "안내가 어렵다"를 근거 위에서 답하기 때문이다. 임계값 조정과
   미끼 강화가 다음 실측의 입력이다.
3. **RAG 심화** — 벡터 단독 → 하이브리드(BM25+벡터) → 리랭킹 비교, 단계별 recall@k·precision.
   청킹 전략 비교(고정 크기 vs 조항 단위). 기각 사유를 "생성 문제 vs 검색 실패"로 분해.
4. **지표 확장** — 게이트 도입 전후 hallucination 율, L1 필터링에 의한 상위 검증 호출 감소율
   → 건당 비용 절감.
5. **미결** — 대시보드(스택 미정), 웹훅 송출, 배포, MCP.

## 알려진 제약

- **인증 없음.** 실사용자·실운영이 없어 의도적으로 범위 밖에 두었다. 실운영에 올리려면
  인증·인가·레이트 리밋·전송 구간 암호화가 전부 새 결정 사항이다.
- **스키마 마이그레이션 도구 없음.** DDL 이 전부 `CREATE TABLE IF NOT EXISTS` 라 스키마를
  바꾸면 볼륨째 재생성해야 한다.
- **정상 실행 0건 SQL 은 처리 기록에 흔적이 없다.** 채택된 근거도 실패도 아니라서 저장할
  자리가 없다. 감사에 필요하면 스키마 변경 사안이다.
- `starlette` + `httpx` 조합에서 테스트 클라이언트 deprecation 경고 1건. 현재는 통과하지만
  상위 버전에서 깨질 수 있다.
