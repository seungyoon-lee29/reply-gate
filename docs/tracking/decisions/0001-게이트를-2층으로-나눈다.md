# 0001. 게이트를 결정론 층과 확률 층으로 나눈다

## 맥락

"근거 없는 답변을 기각한다"를 구현하는 가장 직관적인 방법은 LLM 에게 초안과 근거를 주고
"이 답변이 근거에 부합하는가"를 묻는 것이다. 한 번의 호출로 의미 수준까지 검증된다.

그런데 그렇게 하면 **게이트 자체가 확률적**이 된다. 검출률·오탐률을 재면 그 수치가 다음 실행에
재현되지 않고, 게이트가 놓쳤을 때 원인이 프롬프트인지 모델인지 근거인지 분리되지 않는다.
이 프로젝트의 차별화 축이 신뢰성 지표이므로, 지표가 흔들리면 서사 전체가 무너진다.

## 결정

게이트를 두 층으로 나누고 **이번 사이클은 결정론 층(L1)만** 만든다.

- **L1(코드)** — citation 존재·참조 무결성·스키마 준수·패턴형 PII. LLM 호출 0회, 100% 재현.
- **L2(미구현)** — L1 통과분만 claim 단위로 근거와 대조하는 의미 수준 검증.

L1 은 순수 함수이며 `anthropic`/`openai`/네트워크 라이브러리를 import 하지 않는다.
이 제약을 AST 기반 구조 테스트로 못박았다.

## 고려했지만 택하지 않은 것

- **LLM judge 단일 층** — 한 번에 의미까지 본다. 기각했다: 지표가 재현되지 않고, 게이트가
  스스로를 검증할 수 없다("LLM 이 만든 것을 LLM 에게 물어 증명한다"는 순환).
- **L1 을 만들되 L2 를 전제로 얇게** — L1 을 통과 필터 정도로만 두고 실제 판정은 L2 가 한다.
  기각했다: L2 가 없는 동안 게이트가 아무것도 막지 못해 데모가 성립하지 않고, L2 가 단일
  실패점이 된다.

## 결과

- **얻은 것**: 검출률 100% / 오탐률 0% 를 재현 가능한 숫자로 말할 수 있다. 게이트가 놓치면
  코드 한 줄까지 짚을 수 있다. L1 만으로도 게이트가 동작하므로 상위 층은 단일 실패점이 아니다.
- **잃은 것**: 내용상 오류를 잡지 못한다. 정책 문서에 일부러 심은 모호·상충 조항이 그대로
  통과하고, 근거를 오독한 답변도 통과한다. 첫 실측에서 기각 재현율 0% 가 나온 것도 같은 결이다 —
  모델이 값을 지어내지 않아 **구조적** 결함이 만들어지지 않았고 L1 은 구조만 보기 때문이다.
- **불가능해진 것**: "이 게이트가 hallucination 을 막는다"고 말할 수 없다. 막는 것은 구조적
  근거 결함이며, 그 한계를 문서와 면접 서술에 그대로 남기는 것이 이 결정의 일부다.
