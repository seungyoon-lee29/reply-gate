## 함정 — 코드도 git 도 말해주지 않는 것

- **검증 건수 인용을 코드와 **같은 커밋**에 넣어라.** 예전 규율("코드 커밋이 끝난 뒤에 적어라")이
  뒤집혔다 — 스위트가 인용을 대조하므로 미루면 그 사이 커밋이 RED 다.
  전문은 `docs/engineering-notes.md` "문서가 문서를 검증하던 자리" 절.
- **`pytest -q` 를 직접 주면 `-qq` 가 되어 요약 줄이 사라진다**(addopts 에 이미 `-q`).
  건수를 세려면 `--collect-only`.
- **건수 대조는 전체 스위트에서만 돈다.** 경로·`-k`·`-m` 을 주면 사유를 담아 skip 된다 —
  부분 실행에서 초록인 것은 "대조했다"가 아니다. **테스트 건수 쪽은 DB 까지 필요하다.**
- **게이트를 세웠으면 그 자리를 그 세션 안에서 한 번 뒤집어 봐라.** "검사를 지우면 빨개지는가"는
  통과해도 **"검사가 겨냥한 상태를 만들면 빨개지는가"** 는 통과하지 못하는 자리가 실제로 넷
  있었다. 환경을 그 상태로 만드는 한 줄(`POSTGRES_PORT=1 uv run pytest`)이 첫 번째를 잡았다.
  전문은 `docs/engineering-notes.md` "게이트를 세운 세션은 그 게이트를 통과한 유일한 세션이다".
- **`timeout` 명령이 이 환경에 없다**(macOS). 장시간 명령은 Bash 도구의 `timeout` 인자로.
- **오케스트레이터의 Bash cwd 는 호출 사이에 유지된다.** 모든 명령을
  `cd /Users/ian/workspace/reply-gate` 로 시작하는 것이 안전하다.
- **zsh 는 따옴표 없는 변수를 단어 분할하지 않는다.** `for id in $IDS` 는 여섯 개를 한 덩어리로
  넘긴다 — `${=IDS}` 를 써라(실기동 확인 중에 한 번 걸렸다).
- **`scripts.evaluate` 는 `--live`·`--stub-llm` 없이 부르면 무과금이다** — 측정 2·3 을
  "미실행 + 사유"로 건너뛰고 측정 1 만 돈다(LLM 호출 0회).
  **`--measurements` 는 2·3 만 고른다** — `--measurements 1` 은 거부된다.
- **`.dryforge/005/handoff.md` 는 자기 아카이브 이전 상태로 굳어 있다.** 스냅숏으로 읽어라.

**이번에 얻은 규율은 전부 `docs/engineering-notes.md` 로 옮겼다** — 검사가 "있다"와 "문다"의
차이(분기별 격리 입력 + 뮤테이션 실증) · 링크 검사기의 함정 셋 · 문서 건수 대조의 모집단 규칙 ·
비밀은 담는 것과 내놓는 것이 다르다 / 규칙을 좁히지 말고 예외를 등재해라. 여기 두지 않는다.
