## 함정 (이번 사이클이 실제로 밟은 것)

- **τ 는 임베딩 모델에 묶인다.** `-3-small` 1536 에서만 분리했고 `-3-large` 계열은
  분리하지 못했다(여유 −0.0114 / −0.0160). 임베딩을 건드리면 게이트가 **조용히 무력해진다.**
  런타임에는 이걸 막는 장치가 없다 — 리포트 지문의 짝 하나가 전부다.
- **병렬 실행은 리포트 번호를 미리 갈라 줘야 한다.** 하네스 자동 넘버링은 각 워크트리가
  base 까지만 보므로 같은 번호를 고른다. `--report-stem` 으로 구간을 나눠 줘라.
- **리포트의 사람이 읽는 줄과 조건 지문이 갈릴 수 있다.** `-19`~`-24` 의 `conditions.judge`
  가 전부 `claude-sonnet-5` 로 잘못 적혔다. **정본은 `condition_fingerprint`** 다. 코드는
  고쳤고 산출물은 보존했다(결정 0018 "산출물 결함" 절).
- **설정 객체가 repr 되면 자격 증명이 따라간다.** 단언식 안에 `Settings(...)` 를 두지 마라 —
  bool 로 먼저 묶어라. Postgres DSN 경유 노출은 **검증하지 않았다.**
- **커밋된 라이브 리포트를 고치려고 다시 사지 마라.** 틀린 것이 사람이 읽는 줄이고 기계가
  읽는 값이 맞으면, 정정은 문서 쪽이다.
- **`--stub-llm` 이 DB 임베딩을 대역으로 덮어쓴 사고가 보고됐으나 기전을 재현하지 못했다.**
  코드상 stub 경로는 롤백을 건다. 라이브 전에 색인 출처를 확인하는 절차만 남겼다
  (`docs/engineering-notes.md` 가 "확인한 것 / 확인하지 못한 것"으로 갈라 적었다).
- **테스트가 개발자의 `.env` 를 읽는다** — 인자 없는 `Settings()`. "기본값이 결정대로인가"를
  재는 테스트가 로컬 환경을 재게 된다.
- **링크 검사는 프래그먼트까지.** 앵커 무시 검사기가 "0건 깨짐"을 잘못 말한 전례가 있다.
- **확률 층 장면에 "항상"을 붙이지 마라.** "3/3"은 관측이지 결정론이 아니다.
- **설계 세션은 없다 — 이 3-doc 이 전부다.** 문서로 안 풀리면 추측하지 말고 사용자에게.
  소스 주석은 durable 문서만 인용한다(`tests/test_durable_citations.py` 가 막는다 — 이
  3-doc 을 소스에서 인용하지 마라).
