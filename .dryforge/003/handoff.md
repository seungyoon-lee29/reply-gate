## 하드 게이트 (코드에서 유도할 수 없는 불가침)

1. **게이트 두 층의 판정을 느슨하게 하지 않는다.** 사유 4종·2종, L1 의 LLM·네트워크 import
   금지, L2 의 배치·fail-closed. 사이클 3 중 `gate.py`·`judge.py` 수정 4건은 적대리뷰가 찾은
   결함 수정(정의 확장·오탐 제거·대조 강화)이지 완화가 아니다 — 그래서 L1 PII 정의가 넓어져
   사이클 1·2 수치와 직접 비교할 수 없다(`status.md`). 검색이 좋아졌다고 판정을 건드리지 마라.

2. **재작성 질의 픽스처는 런타임으로 새면 안 된다.** `data/rewritten_queries.jsonl` 은
   오프라인 비교 전용. 구조 테스트가 AST 로 못박고 있고 **문자열 상수·docstring 까지 본다 —
   `#` 주석은 못 본다**(AST 밖이다). 가드를 느슨하게 하지 말고 문장을 바꿔라.

3. **검색 단계 실패는 폴백, 배선 누락은 조립 오류.** L2 호출 실패가 인계인 것은 변함없다.
   (`docs/business-rules.md` "검색 단계 실패" 절이 T11 에서 명문화했다.)

4. **조용한 폴백 금지 · 토큰 은폐 금지.** 검색 계열 토큰은 생성·임베딩·판정 어디에도 합산 금지.

5. **평가 장치 제거 금지.** 미끼·모호·상충 조항, 골든셋, `l1_fixtures`·`judge_fixtures`·
   `retrieval_labels`·`rewritten_queries`·`rewritten_queries_oracle`.

6. **라벨은 채점자만 본다.** 어떤 검색 전략도 정답 라벨을 입력으로 받지 않는다.

7. **산출물 보존.** 라이브 실측 9회분 18개 파일 + `retrieval-*` 리포트는 덮어쓰기·삭제 금지.
   훅이 못 잡는 경로(스크립트 재실행)는 하네스가 스스로 거부한다(`resolve_report_stem`).

8. **과금은 명시적으로만.** 라이브 실측은 실행 직전 확인. 상한 $10. 비밀은 `.env` 에만.

9. **볼륨 재생성 전 사용자 확인 + 처리 기록 백업·복원, 복원은 API 로 실제 열어 확인.**
   findings 19 가 이 조항 위반의 실측 사례다(08-13 재생성에서 보존 대상 2건 유실, 미복구).

10. **미달이면 원복이 기본 · 실측이 정당화하지 않는 기본값을 남기지 않는다.** T10 이 실제로
    탔다(`72ff2d4`) — 축별 원복은 사용자 결정이었고 결정 0011 이 들고 있다. **spec §10-3
